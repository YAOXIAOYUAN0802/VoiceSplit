# 人声 / 背景音乐分离工具

一个带界面的本地工具：把视频或音频里的人声和背景音乐分开，全程在本机运行，不需要联网，不上传任何文件。

---

## 快速开始

双击 **`人声伴奏分离工具.exe`** 即可打开。

### 分离音频

1. **选择文件** → 点「浏览…」选你的视频（mp4 / mov / mkv / avi 等）或音频（mp3 / wav / flac / m4a 等）
2. **输出文件夹** → 不填会自动在源文件旁边建一个「分离结果」文件夹
3. **分离设置**
   - 分离内容：勾选「人声」「伴奏」（默认都勾）
   - 模型档位：标准 / 高精度 / 轻量快速
   - 附加格式：需要 FLAC 无损或 M4A 压缩就勾上，另外还可以导出 15 秒试听片段
   - 输出电平：默认 0.95 倍（留 −0.4 dB 余量，避免剪辑软件里爆音）
4. **处理范围** → 想先试效果就取消「处理整个文件」，填起始秒数和时长
5. 点 **开始分离**，进度和日志在下方实时显示

输出文件名形如 `原文件名_人声.wav`、`原文件名_伴奏.wav`。

### 片段替换

如果想用重新处理过的某一小段，去替换主音频里对应的区间：

1. 选**主音频**（要保留的完整音轨）
2. 选**替换片段**（新做好的那一小段）
3. 填**插入起点**（比如 `125` 表示从 2 分 05 秒开始替换）
4. 点「执行替换」

程序会自动测量两者的对齐偏移（补偿 MP3 编码延时，不会错位），边界做 20ms 交叉淡化防止爆音，替换区间之外**不改动任何样本**。原文件会先备份成 `*_替换前备份.wav`。

## 模型档位说明

| 档位 | 模型组合 | 频谱参数 | 特点 |
|---|---|---|---|
| 标准（推荐） | Kim_Vocal_2 + UVR-MDX-NET-Inst_HQ_3 | n_fft 6144 | 速度与质量平衡，一般素材够用 |
| 人声突显（歌曲） | kuielab_b_vocals + Inst_HQ_3 | 4096 / 6144 | 人声专用模型，背景音乐残留最低 |
| 高精度 | UVR-MDX-NET-Voc_FT + Inst_HQ_4 | n_fft 6144 / 5120 | 人声更干净，耗时与标准档接近 |
| 轻量快速 | Kim_Vocal_2 + UVR-MDX-NET-Inst_Main | n_fft 6144 / 4096 | 伴奏模型更小更快，质量略降 |

> 不同 MDX-Net 模型使用的 FFT 窗口长度并不相同（6144 / 5120 / 4096）。程序会自动读取每个模型的输入维度并配套生成频谱，无需手动设置。

**速度参考**：3~4 分钟的歌曲，标准档约 4~5 分钟（CPU 推理，无显卡加速）。

### 三个关键开关（背景音乐去不干净时先动这里）

1. **分离方式**
   - **干净优先（掩蔽式）** ← 默认。把模型输出当作 0~1 的权值直接过滤原曲，模型没把握的地方能量留在伴奏轨，不会糊进人声。
   - **快速（互补式）**：伴奏取模型输出、人声取相减。快，但音乐响时人声里会残留音乐。

2. **人声优先 / 突显人声**（歌曲素材强烈建议勾选）
   自动换用对人声提取更强的模型；若素材是多声道（如 5.1 环绕），还会用中置声道做先验——环绕混音里人声通常就在中置。这一项对"背景音乐太大"的歌曲帮助最大。

3. **分离强度**
   - **常规**：保留细节。
   - **强分离**：判据更果断 + 时域门控，人声概率低的时间段（间奏、换气）整体压低。
   - **纯人声（极端隔离）**：两趟迭代提取——先分出人声，再把结果喂回模型二次提取，背景音乐可压到接近消失。整首歌实测背景音乐残留 **0.24%**（强分离是 1.2%，常规是 12.1%），代价是耗时约 2 倍、人声会有轻微处理感。

   | 强度 | 整首歌背景音乐残留 | 人声频段保留 | 3:45 歌曲耗时 |
   |---|---|---|---|
   | 常规 | 12.1% | 81% | 约 4 分钟 |
   | 强分离 | 1.2% | 57% | 约 4 分钟 |
   | 纯人声（极端隔离） | **0.24%** | 59% | 约 8 分钟 |

## 技术说明

- **算法**：MDX-Net（与 Ultimate Vocal Remover 同款模型），44.1kHz 立体声处理
- **互补渲染**：人声轨由「原曲 − 伴奏」得出，因此 `人声 + 伴奏` 相加可还原原曲（量化噪声级别，平均偏差 < 0.001%）
- **共用增益限幅**：以混合信号计算一条平滑增益包络，两条音轨共用，只在 0.4% 左右的峰值区介入，既防削顶又不破坏互补关系
- **输出电平**：默认真峰值控制在 −1 dBTP 以内，无削顶样本
- **不重编码视频**：工具只输出音频轨，不会动你的原视频文件

### 支持的输入格式

输入靠 ffmpeg 解码，常见格式都支持：mp4、mov、mkv、avi、flv、wmv、ts、webm、mp3、wav、flac、m4a、aac、ogg、wma。

### 想换其他模型？

把任意 MDX-Net 的 `.onnx` 模型放进程序目录的 `models` 文件夹，重启程序即可在「模型档位」里看到新的组合（需要同时具备一对人声/伴奏模型才会显示档位）。

## 常见问题

**问：为什么输出只有 2 分 18 秒，比视频短了一点点？**
答：结尾 0.04 秒是算法边缘淡出区，听不出来。

**问：为什么音量比原视频小一点？**
答：故意留的余量（约 −1.4 dBTP），避免在剪辑软件里叠加效果后爆音。需要更响就把「输出电平」调到 1.0，或后期自己加增益。

**问：处理后还能完美还原原曲吗？**
答：可以。两条音轨相加等于原曲乘以你设定的输出电平系数（默认 0.95），把两轨相加后再提升约 0.45 dB 即与原曲一致。

**问：能处理多长的文件？**
答：几百 MB 的视频没问题，处理时间大致是音频时长的 1.7 倍。

## 出问题时怎么办

1. 双击 **`启动（含自检）.bat`**，它会先打印诊断信息再打开界面。
2. 也可以手动运行 `人声伴奏分离工具.exe --selftest`：它会逐项检查 ffmpeg、模型、推理链路，并跑一遍完整流程（含全部模型档位）。
3. 运行日志：`%TEMP%\人声伴奏分离工具_运行日志.txt`（在资源管理器地址栏输入 `%TEMP%` 回车即可打开该目录）。
